WORLD KNOWLEDGE FORUM 2026

Event Identity & Design Operations

제27회 세계지식포럼(2026.9.8–10, 장충아레나·신라호텔)의 디자인을 총괄했다. 주제 'The Promethean Moment: Architecting the Co-Intelligence Order(프로메테우스의 순간: 공존지능 세계를 설계하라)'를 키비주얼로 만들고, 비주얼 가이드를 통해 PCO와 제작 업체가 같은 비주얼을 쓰도록 했다.

키비주얼부터 국·영문 웹 초청장, 소책자·리플렛, 홈페이지, 현수막·현수기, 굿즈와 이벤트 키트까지 원고 취합 → 디자인 → 발주 전 과정을 맡았다.

매일경제 세계지식포럼 · 디자인 총괄 Key Visual · Editorial · Web · Signage · Goods Illustrator, InDesign, Photoshop, Framer

프로메테우스의 순간:
공존지능 세계를 설계하라

Brief

AI와 인간의 공존지능을 다루는 27번째 포럼. 사흘 동안 두 행사장과 온라인, 인쇄물, 굿즈에 같은 인상을 남겨야 했다.

Approach

불꽃 그라데이션 기둥 하나를 키비주얼로 두고, 컬러·크롭·블렌드 모드 변주만으로 모든 매체에 적용하도록 가이드를 만들었다.

Scope

키비주얼·가이드 / 웹 초청장(국·영문) / 소책자·리플렛 / 홈페이지 운영 / 현수막·현수기 / 굿즈·이벤트 키트

01

Key Visual키비주얼

프로메테우스의 불꽃을 세로 기둥으로 나눈 그라데이션입니다. 높낮이가 다른 기둥은 불꽃이면서 동시에 막대그래프처럼 읽힙니다. 배경, 하프톤 레드, 다크 버전으로 매체에 맞춰 바꿔 씁니다.

02

Guide비주얼 가이드

PCO와 제작 업체에 전달한 7쪽 가이드입니다. 메인·서브 컬러, 서체(카카오 작은글씨, 에스코어 드림, Bebas Neue), 로고 사용 규정, 레이아웃, 블렌드 모드 변주(Lines · Multiply · Soft Light · Vivid Light)를 정리했습니다.

03

Editorial소책자 · 리플렛

국·영문 소책자는 InDesign, 리플렛은 Illustrator로 만들었습니다. 원고 취합과 연사 사진 편집, 인쇄 발주까지 맡았습니다.

04

Digital웹 초청장 · 홈페이지

Framer로 국·영문 웹 초청장과 여성포럼 초청장을 만들어 배포했습니다. 홈페이지는 개발자와 협업해 이미지·오픈 일정·계정을 관리했고, 유튜브와 온라인 배너도 같은 비주얼로 맞췄습니다.

05

Event Kit이벤트 키트

웰컴카드, 스티커, 노트, 마스킹테이프, 마그넷, 펜으로 구성한 키트를 기획 시안부터 발주용 파일까지 만들었습니다.

06

Signage현수막 · 현수기

장충아레나 외벽 통천과 가로 현수기, 도심 대형 배너까지 원고 취합과 이미지 편집, 발주 파일 전달을 맡았습니다.

07

On Site행사장

메인 무대 LED, 안내 데스크, 이벤트 부스까지 행사장 곳곳에 같은 키비주얼이 이어집니다.
